# Astronomische Uhr

Eine einzelne HTML-Datei, die Sonne, Mond und Erde als Uhr zeigt: Ortszeit, Auf- und Untergänge, Mondphase, Tag und Nacht auf der drehbaren Erde. Ort wählbar per Suche, Liste oder Fingertipp auf den Globus, auch Nord- und Südpol.

**Datei:** `astro-uhr.html` (alles eingebaut, läuft offline, kein Server nötig). Für GitHub Pages in `index.html` umbenennen.

**Benutzung:** Datei im Browser öffnen. Beim ersten Start fragt die Seite nach dem Standort oder lässt einen Ort wählen. Der Standort bleibt im Browser des Geräts, es wird nichts gesendet. Über HTTPS (zum Beispiel GitHub Pages) funktioniert die Standortabfrage am zuverlässigsten, bei lokal geöffneten Dateien blockieren manche Browser sie.
